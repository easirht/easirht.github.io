Skills

My technical foundation is in mechanical systems: machine design, thermal and fluid systems, HVAC and refrigeration, manufacturing planning and CFD fundamentals, backed by hands-on work in ANSYS, SolidWorks and AutoCAD. On top of that I build machine learning tools in Python (PyTorch, TensorFlow/Keras, scikit-learn), from physics-informed neural networks and LoRA-based continual learning to vibration-based fault diagnosis. I give evaluation as much weight as the models themselves, using group-aware cross-validation, bootstrap confidence intervals and calibration checks so that results hold up on real systems.
